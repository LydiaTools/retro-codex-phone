# Console design

Subject: a retro handset dispatching spoken work to an AI coding assistant.

The layout is a telephone control strip on the left and a working transcript/reply surface on the right. The red handset and record button are the one memorable element. Labels describe actual controls, not a marketing presentation.

Palette: shell blue-grey #E6EDF2, control panel #D7E2E9, white #FFFFFF, ink #22323E, signal red #CB2D39, action blue #18394D. Avenir Next/Segoe UI provide readable native typography; left-aligned 14–16px copy and a 30px title keep the controls legible. No automatic decorative motion, external fonts, generated pictures, or fake user data.

The transcript stays in one editable area. Hardware diagnostics and microphone selection stay visible. Below 760px the control strip stacks above the transcript. Keyboard focus is visible, status and errors have accessible roles, and busy operations disable conflicting controls.
