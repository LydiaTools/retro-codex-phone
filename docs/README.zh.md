# 复古电话 × Codex / Claude

一个独立实现的本地语音控制台：把能作为电脑麦克风的复古听筒接上，录音转成可编辑的指令，再由你确认送给 Codex CLI 或 Claude Code，结果回到同一控制台。

## 新增的实际价值

- 每次明确选择 AI 和项目目录，指令不会因为光标切换而落到其他窗口。
- 录音后可检查、修改文字，再发送；默认只读/规划，修改项目文件需要主动开启。
- 双击播放键开始/结束录音；加号发送；减号在指令里退格。也有屏幕按钮。
- 麦克风可选，线控按键有测试模式；“声音能用”和“按键能用”分开验证。
- 当前结果可查看、可朗读、任务可停止；没有常驻录音或自动开机服务。

这些改进服务“给一个指定代码项目下语音任务”，不是宣称在所有方面超过已有输入法。

## 开始

安装 Python 3.11 以上版本，以及已登录的 Codex CLI 或 Claude Code。下载 [Release ZIP](https://github.com/LydiaTools/retro-codex-phone/releases/latest)，解压后使用对应系统启动脚本，或按主 README 的命令运行。

1. 接上听筒，在系统声音设置验证它是输入设备。
2. 打开 `http://127.0.0.1:8768`，选择现有项目目录。
3. 点击 Prepare local voice，首次下载本地 Whisper 模型；选择听筒麦克风。
4. 录音、停止、检查转写、发送。
5. 需要线控时先启用按键测试，再逐个按键确认。部分3.5mm/USB-C转接头只有声音，没有媒体按键信号。

视频展示的是工作室的桌面听写玩法。本仓库是配套重新实现的 CLI 控制台，不修改 Codex/Claude 客户端，也不使用私人接口。

macOS 已做源码编译、实际音频转写及程序逻辑核验；实际听筒按键仍需按你的设备验收。Windows 源码/启动器提供，真机验收待补。准确范围见 [VERIFICATION.md](VERIFICATION.md)。
